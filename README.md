# Chamang-Inference

## 평산 최아지·이차망 옥사: 사료·검증·가능세계

정조대 평산 최아지 옥사(1785~1789)를 대상으로, **문헌에 기록된 행위**와 **서술된 혐의 및 당시 판단**, **후대 연구자가 검토할 수 있는 가능세계**를 분리하는 역사·서사 분석 프로젝트입니다.

> **연구 상태: 예비 사료조사 / 미검증 구간 존재.** 《심리록》·《추관지》·1787년 《정조실록》 관련 기사는 조사했지만 《승정원일기》·《일성록》·《비변사등록》은 관련 항목 전체를 아직 대조하지 않았습니다. 가능세계 7건은 **가설 후보**이며 계산된 확률이나 확정 진실이 아닙니다.

### 역사적 핵심
- **1785년** 박씨 사망 사건에서 최초 검험은 자해를 제시했고, 유족은 타살을 주장했습니다.
- **1786년** 이차망의 아내 민씨는 남편을 위한 격쟁을 했습니다.
- **1787년** 이곤수의 안핵을 거쳐 이차망의 석방을 명했으며 조광진의 자백과 사단의 진술 변경이 기록됐습니다.
- **1789년** 정조는 앞선 안핵의 판단에 다시 30개 의문을 제기했고, 최아지에 대한 장 100·유 2천 리 준용 처분을 승인했습니다. 사형 확정이나 완전 무죄 판결로 오독해서는 안 됩니다.

### 핵심 구별
| 유형 | 원칙 |
|---|---|
| DOCUMENTED_ACT | 사료가 전하는 실제 보고·처분·신문·격쟁 행위의 존재를 기록 |
| ATTESTED_CLAIM | 진술이 나왔다는 사실과 그 **내용의 진실**을 분리 |
| DISPUTED_INFERENCE | 사인·범인·동기·상흔 해석은 충돌 상태로 보존 |
| LATENT_EVENT | 기록 공백을 채우는 설명은 후보세계로 표시하고 사료 사실로 승격 금지 |

**주의:** GuSoon-Inference의 1793년 사건별 데이터와 가능세계 결과는 이 저장소에 이식하지 않습니다. 방법론과 검증 규칙만 참조합니다.
