# Chamang-Inference: 데이터 모델 및 검증 규칙

> 범위: 1785~1789년 황해도 평산 최아지·이차망 옥사. 본 저장소는 연구 초고이며 전체 사료 수집 또는 역사적 사실 확정을 의미하지 않는다.

## 자료 원칙
1. **문헌 원문과 편찬 서술의 독립성:** 《심리록》과 《추관지》는 일부 공초와 왕명을 공유하므로 독립 표본 2개로 계수하지 않는다.
2. **행위와 진실값 분리:** “조광진이 자백했다”는 기록되는 행위이며 “조광진이 실제 범행했다”는 별도 검증 대상이다.
3. **불확실성 유지:** `NOT_YET_IDENTIFIED` 자료를 미존재 자료로 취급하지 않는다. `VERIFIED_DIRECT`는 문헌 읽기 여부이며 사건 진실성 100%가 아니다.
4. **시간 제약:** 1785년 현장에 1786년 법령 시행 효과나 1792년 개정 지침을 소급하지 않는다.
5. **가능세계:** 사망 경위 및 증인·자백 신뢰도에서 여러 설명을 분기하되, 기록된 조사·왕명·석방이라는 절차 행위는 고정한다.
6. **표현:** 극화 또는 동기 창작은 `NARRATIVE_LICENSE`로 표시하고 `DOCUMENTED_ACT`와 혼합하지 않는다.

## 분리해야 할 분석 단위
- `source_records`: 출처 ID, 편찬시점, 문서종류, 접근 URL, 검증상태, 근원 문서 일치 그룹.
- `attestations`: 한 출처가 한 명제를 보고한 행위(누가, 언제, 누구의 공초인지).
- `procedural_events`: 보고·안핵·신문·격쟁·처분·석방 등 기록된 행정 사건.
- `claims`: 자살/타살, 특정인 범행, 진술 신빙성처럼 참값이 미정인 내용.
- `contradictions`: 서로 충돌하는 사인·행위자·진술·순서 판단.
- `world_candidates`: 기록과 제도에 부합하는 미확정 가능한 설명.
- `normative_features`: 해당 사건 날짜에 유효한 법·제도의 조건.

## 검증을 추가해야 하는 부분
- 《승정원일기》 및 《일성록》 관련 기사 구체적 확인
- 《비변사등록》 해당 사건 존재 여부
- 문헌 원문 문장별 source_span 수집과 번역 대조
- 《심리록》·《추관지》의 동일 근원 진술 중복그룹 부여
- 양력·음력 변환과 각각의 처분·행위 시점 확인
- 1789년 승인된 형벌의 실제 집행과 후속 생애 확인

## 현재 산출물
- `data/source_records.csv`: 보고서 출처와 현 단계 확인 상태
- `data/world_candidates.csv`: 7건의 예비 가능세계/신뢰도 후보
- `reports/pyeongsan_case_report.md`: 주제·인물·연표·30의문·가능세계의 경계에 대한 연구 보고서
- `index.html`: 위 자료를 요약한 정적 HTML 탐색 인터페이스

## 구현 주의
이 단계에서는 *가능세계의 사후확률을 계산하지 않는다*. 상충하는 후보를 7개 기록했다는 것만으로 확률 분포가 형성되지 않는다. 또한 W05·W06은 서로 배타적인 범행세계가 아니라 증거 신뢰도에 관한 축이므로 후보세계의 조합을 구성할 때 각각 별도의 latent variable로 취급해야 한다.
